# Onboarding Workflow

## MVP manual onboarding
1. Collect artist profile info and contacts.
2. Add new artist object in `src/lib/artist-data.ts`.
3. Add images and story sections.
4. Verify `/artists` and `/artists/[slug]` render.

## Future assisted workflow
- Admin UI form with validations, media upload, and preview.

## Future WhatsApp self-serve workflow
- Artist sends intro message, bio, media, and updates via WhatsApp.

## Required inputs checklist
- Name, slug, tagline, location, categories, languages.
- WhatsApp number, optional Instagram/email.
- Short and long bio, philosophy.

## Photo/video/interview checklist
- Portrait image.
- Hero image.
- At least one featured artwork.
- One before/after sample.
- Optional interview video URL.
